PULSE Performance Analytics
Privacy Policy

PULSE Performance Analytics (“PULSE”) is a personal fitness analytics application designed to help its operator review health and training trends. This policy describes its intended use of WHOOP information. The application is intended for private, personal use and is not currently offered as a public service.

Information accessed

With the account holder’s authorization, PULSE may request WHOOP data made available through approved API permissions, including recovery, sleep, physiological measurements, activity, workout, cycle, and profile information. Only data permitted by the account holder and provided by WHOOP will be accessed.

Purpose of processing

The information is used to display historical trends, analyze training and recovery patterns, and generate personal fitness insights. PULSE does not use WHOOP information for advertising or sale.

Storage and security

The intended configuration stores retrieved data on the operator’s own computer. The operator is responsible for securing that computer, the application’s configuration, and any locally stored data. If hosting, cloud storage, analytics, or external AI processing is enabled in the future, this policy must be updated before those services process WHOOP information.

Sharing

PULSE is not intended to sell or share WHOOP information with advertisers or data brokers. Data may pass through WHOOP’s authorization and API systems as required to connect the account. No other sharing is intended in the personal-use configuration described here.

Retention and deletion

Locally stored WHOOP data is retained until the operator deletes it. Revoking WHOOP authorization stops future authorized retrieval but may not automatically erase data previously saved locally; those files or database records must also be deleted.

Account control

The account holder may withdraw authorization through WHOOP’s available connected-application controls. The operator can stop running PULSE and delete locally stored information.

Children

PULSE is not designed for use by children and is intended solely for the adult operator’s personal account.

Changes

This policy may be updated if the application’s features, storage methods, or data-sharing practices change. The updated policy will be posted at this URL with a revised date.

Contact

For privacy inquiries, contact the application operator using the contact information provided in the WHOOP developer application registration.

Note: This policy must be reviewed against the application's actual implementation before publication. It does not replace any WHOOP developer requirements.
